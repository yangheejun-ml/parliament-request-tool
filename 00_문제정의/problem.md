# 문제정의서 (5칸)

| 칸 | 내용 |
|---|---|
| ① 현재 업무 | A부 국회 업무 담당자가 요구서를 문항 단위로 접수하고 접수대장에 기록한다. 요구내용과 배분기준표를 대조해 26개과 중 소관과를 정하고, 주관과와 협조과로 배분한다. 각 과의 회신을 추적·취합하고 누락, 요구기간, 조직명, 합계, 중복, 기한, 서식을 점검한 뒤 담당자 확인과 결재를 거쳐 제출하고 이력을 남긴다. 2026년 접수대장은 520건이며 소관 450건, 공통 70건이다. 처리상태는 제출완료 412건, 기한연장 55건, 보완요청 53건이다. |
| ② 문제 | **시간:** 520건을 26개과에 배분해야 하고 접수일부터 제출기한까지 2~7일밖에 없어, 흩어진 지침과 기준표를 사람이 매번 찾고 대조하는 작업에 시간이 걸린다. **오류:** 공통 70건은 여러 과의 회신을 모아야 하며, 대장의 동일 요구문구는 39개 집단·98건으로 접수 중복인지 사람이 다시 판단해야 한다. 누락·기간역전·기한이상·조직명·합계·서식 오류도 수작업 점검에 의존한다. **사람마다 다른 점:** 배분 키워드가 여러 과에 걸리거나 기준표에 없으면 담당자의 조직도 해석과 경험에 따라 후보와 주관과가 달라질 수 있다. **이력 단절:** 현재 대장은 최종 배분과와 처리상태만 남기므로, 누가 언제 무엇을 왜 배분·재배분·확인했는지 연결해 추적하기 어렵다. |
| ③ 목표 | 520건을 같은 기준으로 구조화하고, 조직도에 있는 26개과 안에서 소관과 후보와 근거를 제시하며, 누락·중복 후보·기간·기한·조직명·서식 확인 항목을 자동 표시한다. 시험 자료 40건에서 소관과 **1순위 정확도 75% 이상**을 달성한다. 최종 판단은 사람이 하고, 판단자·시점·변경내용·이유를 이어서 남긴다. |
| ④ 범위 | **만들 것:** 요구자료의 문항 단위 구조화, 접수대장 필수값 확인, 배분기준표·조직도 기반 소관과 후보와 근거 제시, 주관·협조 후보 구분, 동순위·미매칭·공통·이상값의 확인필요 표시, 배분·재배분·확인 이력 기록. **만들지 않을 것:** 답변 작성·수정, 결재, 국회 제출과 제출 여부 결정. 해당 업무는 모두 범위 밖이다. **사람이 판단할 부분:** 최종 주관·협조과, 중복 여부, 확인필요 항목의 처리, 예외 승인은 담당자가 원문과 조직도를 보고 결정한다. |
| ⑤ 검증 기준 | 시험 요구문항 40건을 담당자가 확정한 소관과와 비교해 1순위 정확도가 75% 이상이면 통과한다. 추천 부서명이 26개과 밖이거나, 동순위·미매칭·공통 문항을 임의로 확정하면 불합격이다. 520건에 대해 필수값·요구기간·제출기한·조직명·동일 요구문구 후보 탐지 결과를 원본 대장과 대조하고, 최종 배분·재배분에서 판단자·시점·변경내용·이유가 남는지 확인한다. 답변·결재·제출 기능이 실행되면 불합격이다. |
