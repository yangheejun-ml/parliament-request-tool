# 문항 목록 생성기

## 목표

작업 폴더 맨 위에 `split.py` 하나를 만들거나 수정한다. 이 코드를 실행하면 `원문/*.pdf`에서 `data/문항목록.csv`를 만들며, 사용자가 교체해 둔 문항목록 기준본과 모든 행·열 값이 일치해야 한다.

## 먼저 확인할 자료

1. `AGENTS.md`의 작업 범위와 금지사항을 따른다.
2. `PROGRESS.md`, `CONTEXT.md`, `problem.md`, `design.md`를 정해진 순서로 읽는다.
3. `처리지침.md` 제2장, `data/문항목록.csv`, 기존 `split.py`, `원문/*.pdf`를 읽는다.
4. 기준본 CSV는 비교가 끝날 때까지 덮어쓰지 않는다. `99_완성본_잠금`은 열지 않는다.

## 구현 규칙

- Python 표준 라이브러리와 `pypdf`만 사용한다. `pypdf`를 먼저 확인하고, 없으면 `pip install pypdf`를 사용자에게 보여 준 뒤 허락받아 설치한다.
- 새로 만드는 코드 파일은 작업 폴더 맨 위의 `split.py` 하나뿐이다. 시작점이 필요하면 [assets/split.py](assets/split.py)를 사용하되, 현재 기준본과 원문에 맞게 조정한다.
- 출력은 UTF-8-SIG CSV이며 열 순서는 `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`로 고정한다.
- 첫 줄에서 위원회와 의원을, `수신:` 줄에서 제출기한을 찾아 `YYYY-MM-DD`로 저장한다.
- `수신:`, `담당 보좌관:`, `끝.`과 이름·연락처는 문항에 넣지 않는다.
- 줄 앞의 `숫자.`는 새 문항이다. `가.`, `나.` 등은 같은 문항의 세부항목이고, 여러 세부항목은 한 셀에서 ` / `로 잇는다. 줄바꿈 문자를 넣지 않는다.
- `※` 줄은 같은 문항의 비고다. 저장할 때 맨 앞의 `※`와 뒤따르는 공백을 제거한다. 여러 비고는 ` / `로 잇는다.
- 그 밖의 줄은 바로 앞 항목에 공백 하나로 이어 붙인다.
- 파일명의 `_숫자문항.pdf` 값과 추출 수·마지막 번호가 같고 번호가 1부터 연속이어야 한다.

## 기준본 대조와 실행

1. 기존 `data/문항목록.csv`를 UTF-8-SIG로 읽어 메모리에 보관한다.
2. 작성한 `split.py`의 파싱 함수를 불러 원문 PDF의 결과를 메모리에서 계산한다. 이 단계에서는 CSV를 쓰지 않는다.
3. `(파일명, 문항번호)`를 키로 행 수, 열 이름, 각 셀을 전부 비교한다. 불일치가 있으면 열별 건수와 대표 차이를 확인해 일반 규칙을 고친다. 특정 문항의 정답을 코드에 직접 쓰지 않는다.
4. 기준본과 완전히 일치한 뒤에만 `split.py`를 실행한다. 실행 후 CSV를 다시 읽어 한 번 더 전수 비교한다.
5. 파일별 `파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)` 표와, 세부항목·비고가 있는 문항 3개의 원문/CSV 나란히 대조표를 보고한다.
6. 하나라도 X면 원인을 고쳐 재실행한다. 모두 O일 때만 완료로 보고하고 `PROGRESS.md`에 완료·검증 결과를 남긴다.

## 끝나는 조건

- 기준본과 생성본의 78개 문항, 8개 열, 모든 셀 값이 일치한다.
- 세부항목에는 줄바꿈이 없고 ` / ` 구분자가 쓰였으며, 비고에는 선행 `※`가 없다.
- 수신·보좌관·끝 문구와 전화번호 의심값이 0건이다.
- 원문 PDF와 기존 다른 `data` 파일은 수정되지 않았다.
